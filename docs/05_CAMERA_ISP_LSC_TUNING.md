# 展锐相机 ISP 调优、镜头阴影校正 (LSC) 逆向与闭环拟合实战

## 1. 现象描述与故障链条

跨机型移植相机闭源栈时，最普遍的画质故障是：
- **“借用其他传感器调优库（如 S5K3L8）可以成功出图，但画面四角极绿/死绿，中间严重偏暗或偏色”**。
- 若不提供任何 `libparam_*.so`，展锐 ISP 算法库 `libispalg.so` 会抛出：
  ```text
  ISP 3A/pm will bypass for NULL sensor_raw_info
  ```
  导致统计缓冲区未初始化，底层在 `camioctl_stream_on` 阶段返回 `-12 (ENOMEM)`，相机 App 崩溃并提示“相机发生错误”。

---

## 2. 展锐 LSC 表二进制物理结构分析

逆向分析 `libparam_*.so`（以 `libparam_s5k3l8xxm3.so` 为例）：
1. **基地址与尺寸**：
   - LSC 数据块位于文件绝对偏移 **`0xbfe34`**；
   - 连续存储 9 张场景/色温表（D65, D50, TL84, CWF, A, U30, NOON 等）；
   - 每张表占用 **4000 字节**，总计 36,000 字节。
2. **网格维度**：
   - 规格为 **20 行 x 25 列** 网格点；
   - 每个网格点包含 **4 个通道**，数据类型为 `uint16_t`（小端序）；
   - 尺寸验证：\( 20 \times 25 \times 4 \times 2 = 4000 \) 字节；
   - 单位增益（Unity Gain，无暗角补偿）数值为 **`1024`**。

---

## 3. 🚨【重大逆向突破】LSC 物理通道交织顺序实证

传统 AOSP 与大多数 Bayer ISP 架构中，4 通道通常按 `[R, Gr, Gb, B]` 或 `[B, Gb, Gr, R]` 排列。

### 3.1 实验排查与假说证伪
在第一轮拟合中，我们若假设通道为 `[R, Gr, Gb, B]`，由于真实镜头存在严重的红蓝边缘光衰（角部光照仅剩中心的 2%~5%），算法会计算出极高的 R 与 B 增益（如 6x~8x），而 G 增益较小（2x~3x）。
当这组数据被写入后，真机实测发现：**四角偏绿非但没有消除，反而演变成死绿（G/R 与 G/B 暴涨至 3.12）！**

### 3.2 空间径向探针验证法 (Radial Channel Probe)
为了彻底查明这 4 个通道的物理硬件对应关系，我们设计了具有空间梯度的径向单通道增益注入探针（中心增益 1x，边缘线性增加至 4x）：
- 提高 **通道 1** 时：四角显著**偏蓝**；
- 提高 **通道 2** 时：四角显著**偏红**；
- 提高 **通道 0 / 3** 时：绿色通道高光溢出（Clip）比例大幅上升。

### 3.3 结论
**展锐 ISP 在该格式下的 4 通道物理硬件顺序严格为：**
> **`[G0, B, R, G1]`** （或等价的 `[Gr, B, R, Gb]`）

此顺序与通用 AOSP 习惯完全逆反！一旦知晓此顺序，将正确的红蓝边缘补偿写入通道 1 与通道 2，四角的恶性偏绿瞬间得到根本性逆转！

## 4. 图像闭环 LSC 反求与迭代拟合引擎

在缺少原厂暗箱标定设备与 OTP 校准数据时，本项目提供基于均匀背景样张反求 LSC 矩阵的闭环算法（`tools/camera/make_lsc_fit.py`）：

1. **光强线性化**：
   \[
   I_{\text{linear}} = \left(\frac{I_{\text{sRGB}}}{255}\right)^{2.2}
   \]
2. **对数二次多项式径向光衰建模**：
   对归一化径向距离 \( u = \frac{(x-x_0)^2+(y-y_0)^2}{(w/2)^2+(h/2)^2} \)，拟合通道衰减曲线：
   \[
   \ln(V_c(u)) = a_c u^2 + b_c u + c_c
   \]
3. **闭环增益注入**：
   \[
   \text{Gain}_c(u) = \left(\frac{V_c(0)}{V_c(u)}\right)^{\alpha}
   \]
   其中 \( \alpha \) 为松弛因子（建议取 0.6 ~ 0.85），防止因过曝区域造成的过度补偿。
4. **生成与热注入**：
   配合 `tools/camera/s126.sh`，在真机上实现无需重启、秒级生效的 ISP 调优热部署。
